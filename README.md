# ZnonClip

**A small, local-first clipboard manager for macOS that predicts your next paste.**

ZnonClip keeps your last 20 copies and up to 20 pins in a native menu-bar app written in Rust and AppKit — no Electron, no webview, no network. The same Cargo workspace ships command-line and agent tools that reuse its storage and secret scrubber.

| Crate | What it is |
|-------|-----------|
| [`znonclip`](crates/znonclip) | The macOS menu-bar app. |
| [`znonclip-core`](crates/znonclip-core) | Shared library: SQLite store and the pre-prompt secret scrubber. |
| [`znonclip-cli`](crates/znonclip-cli) | Terminal interface: `scrub`, `pin`, `stash`, `recent`. |
| [`znonclip-agent`](crates/znonclip-agent) | Agent tools: IPC slots, patch-staging gate, token-budgeted exporter, diff, snapshots. |

## The Mac app

### What it does

- **Last 20 copies, 20 pins.** Text, rich text, HTML, images, file paths and URLs. Pins never expire; unpinned items are pruned after 30 days (configurable).
- **Predicts your next paste.** When the window opens, a local ranker pre-highlights the item you most likely want. It only proposes: the list order never changes, arrow keys move the highlight freely, typing a search switches prediction off, and if ranking fails the highlight falls back to the first row.
- **Pastes for you.** Enter (or a click) copies the item and sends ⌘V to the app you came from. Without Accessibility permission it falls back to copy-only and says so.
- **Opens where you are.** The global hotkey (default ⌃⌘V), a click on the menu-bar icon, or **Option + right-click (or Option + two-finger click) anywhere**, which opens the window at the pointer. A plain right-click is never touched.
- **Three layouts.** A stack by default; the toolbar cycles a two-column view (pinned | recent) and a horizontal strip.
- **Previews.** Hovering a row shows a larger peek; Expand (⌘E) opens a scrollable, selectable view. Images paste at full quality, not as the thumbnail.
- **Per-clip receipt.** The clock-in-chain button (⌘I) shows the item's content SHA-256, what the hash covers, and when it was first and last copied, with Copy buttons. The hash matches `shasum -a 256` of the stored text.
- **Careful editing.** Deleting or unpinning asks first. The pin icon (or ⌃⌘U) unlocks pin editing: the rows shake once, and a click pins or unpins; ⌃⌘L locks again.
- **Remembers the source.** Each clip records the app it was copied from and the app it was pasted into.
- **Float or close.** Keep the window floating on top, or let it close after a paste or an outside click.

### Privacy

ZnonClip follows the [nspasteboard.org](https://nspasteboard.org/) conventions and **checks pasteboard types before reading any data**, so a password manager's copy is never pulled into memory or written to disk. It skips:

- **concealed** content: `org.nspasteboard.ConcealedType` and 1Password's legacy `com.agilebits.onepassword`;
- **transient** content: `org.nspasteboard.TransientType` and the legacy TextExpander, Butler, TypeIt4Me and Typinator markers;
- **auto-generated** content: `org.nspasteboard.AutoGeneratedType`.

History lives only on your Mac, in `~/Library/Application Support/com.znonclip.app/znonclip.db` (SQLite, WAL mode).

### Keyboard

| Keys | Action |
|------|--------|
| ⌃⌘V | Open or close (default; also ⌘⇧V, ⌘⇧C, ⌘⌥V or ⌃⇧V in Settings) |
| ↑ ↓ · Enter | Move the highlight · paste it |
| Type | Search |
| ⌘P | Pin or unpin the highlighted row |
| ⌘E | Expand the highlighted row |
| ⌘I | Show the highlighted row's receipt |
| ⌘⌫ | Delete the highlighted row (asks first) |
| ⌘+ · ⌘− · ⌘0 | Zoom in · out · reset |
| ⌃⌘U · ⌃⌘L | Unlock · lock pin editing (while the window is open) |
| Esc | Close the preview, then the window |

### Settings

Poll interval (500 ms), retention (30 days, 0 = keep), history size (20), auto-paste (on), hotkey preset, float on top (on), zoom, layout, and launch at login.

### Memory

Measured on the running app with [`scripts/measure-rss.sh`](scripts/measure-rss.sh) after 15 days of uptime (2026-10-22): about **8 MB resident** (RSS) and about **50 MB phys_footprint**, the figure Activity Monitor's Memory column shows. Run the script to measure your own.

### Install

**Requires:** macOS 13+, [Rust](https://rustup.rs/), Xcode Command Line Tools.

```bash
git clone https://github.com/ZNONNATURALINTELLIGENCE/znonclip.git
cd znonclip
cargo install --path crates/znonclip   # installs ~/.cargo/bin/znonclip
znonclip                               # starts the menu-bar app
```

Turn on **launch at login** in Settings. A `cargo install` build is a bare binary, so ZnonClip registers a user LaunchAgent (`~/Library/LaunchAgents/com.znonclip.app.plist`) rather than a Login Item, which macOS would reopen through Terminal.

**Accessibility** (System Settings → Privacy & Security → Accessibility) enables auto-paste and lets Option + right-click swallow the app's own context menu. Without it both still work in a reduced form: copy-only, and the app's menu may appear too. macOS ties the grant to the binary, so after rebuilding, toggle ZnonClip off and on again in that list.

### Uninstall

[`scripts/uninstall.sh`](scripts/uninstall.sh) quits the app, removes launch-at-login (including LaunchAgents left by the older ClipPin / Clip Assistant names) and removes the installed binaries. History is kept unless you pass `--purge`.

```bash
scripts/uninstall.sh --dry-run   # show what it would do
scripts/uninstall.sh             # uninstall, keep history
scripts/uninstall.sh --purge     # also delete history, logs and preferences
```

## Command-line and agent tools

These build on any platform:

```bash
cargo build -p znonclip-core -p znonclip-cli -p znonclip-agent
```

The CLI and agent tools keep their own store at `~/Library/Application Support/com.znonclip.ZnonClip/clips.db` (on macOS), separate from the app's history.

### Pre-prompt secret scrubbing

Strip API keys, tokens and mnemonics before text reaches an LLM's context window:

```bash
znonclip-cli scrub "My key is AKIA..."
# → "My key is [REDACTED:aws-key]"
znonclip-cli stash < notes.txt     # store scrubbed text
znonclip-cli recent 10             # list the 10 most recent items (pins marked)
```

### Agent tools

| Command | What it does |
|---------|--------------|
| `znonclip-agent ipc write <slot> <content>` · `ipc read <slot>` · `ipc list` | Share text between agents through local slots instead of git |
| `znonclip-agent stage <file>` · `stage --as <path> < stdin` | Syntax-check code before it touches the filesystem |
| `znonclip-agent export --budget <tokens> <file>...` | Export files truncated to a token budget for subagent prompts |
| `znonclip-agent diff <old> <new>` | Unified diff of slots (`slot:<name>`) or files, no git |
| `znonclip-agent snap create <name> <file>...` · `snap rollback <name>` · `snap list` · `snap delete <name>` | Snapshot files before a risky edit and roll back without touching git |

Each tool has an agent skill in [`skills/`](skills).
